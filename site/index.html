    Good questions

    FAQ

    Is it really free for commercial projects?

    Yes. Everything is MIT licensed — use it in client work, SaaS products and paid apps. Credit is appreciated, never required.

    Why do the web versions feel smoother than a normal Lottie?

    The Web Component, React and JS versions run the Plush runtime, which adds live behaviour on top of the timeline: eyes that follow the pointer with a critically-damped spring, and soft blending when you interrupt one state with another.

    Do they respect reduced-motion settings?

    Yes. With “reduce motion” turned on, looping idles rest on a still pose and only play when the user interacts. The SwiftUI and Compose versions follow the system setting too.

    Where’s the Rive version?

    Rive files can only be authored in the Rive editor, so they’re being rebuilt there by hand. Until then, the Lottie and native versions cover the same platforms.

    Can I change the colours?

    Every format is plain, readable data. Edit the colours in the Lottie JSON or SVG directly, or in the .plush.json and the runtime picks them up.
